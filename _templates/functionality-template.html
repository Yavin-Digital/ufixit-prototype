5. Interactive Features

Feature: Contact Form Submission

Prototype: showPrototypeModal("Thanks! We'll be in touch shortly.")

React: POST to /api/contact via SendGrid. Success → replace form with <SuccessMessage />. Error → inline banner, fields preserved.

// src/components/ContactForm.jsx
const onSubmit = async (data) => {
  const res = await fetch('/api/contact', { method:'POST', body: JSON.stringify(data) });
  if (res.ok) setSubmitted(true);
  else setError('Something went wrong. Please try again.');
};

7. Auth Flow

Type: {{AUTH_TYPE}} (JWT / session-based)

Provider: AuthContext wraps the entire app. useAuth() hook exposes user, login(), logout(), isLoading.

Protected routes: <ProtectedRoute /> wrapper — redirects to /login if unauthenticated.

Token storage: httpOnly cookie (preferred) or localStorage — confirm with backend team.

// src/context/AuthContext.jsx — pattern
export const AuthProvider = ({ children }) => {
  const [user, setUser] = useState(null);
  const login = async (email, password) => { /* POST /api/auth/login */ };
  const logout = () => { /* DELETE /api/auth/session */ setUser(null); };
  return <AuthContext.Provider value={{ user, login, logout }}>{children}</AuthContext.Provider>;
};

9. SEO and AEO Integration

JSON-LD schema: Inject per-page schema via react-helmet-async. One <script type="application/ld+json"> per schema type.

GA4: react-ga4 — initialize in main.jsx with VITE_GA_MEASUREMENT_ID. Track page views on route change.

GTM: Script tag in index.html. Noscript fallback in <body>.

// src/main.jsx
import ReactGA from 'react-ga4';
ReactGA.initialize(import.meta.env.VITE_GA_MEASUREMENT_ID);
router.subscribe(() => ReactGA.send('pageview'));
